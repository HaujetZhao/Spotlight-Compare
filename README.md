# 🔦 图片对比查看 (Image Hover Reveal)

> 纯本地的手电筒式图片对比工具 —— 底图铺满全屏,鼠标悬停处用一个光圈"照出"对比图,挪到哪照到哪。

## 开发动机

AI 出图前后、修图前后的两张图,想快速对比哪里变了。左右并排看眼睛要来回跳,叠在一起淡入淡出又看不清细节。最好的方式是:底图铺满,指哪看哪——悬停处的圆形光圈里透出另一张图,像拿手电筒照暗处,所见即所在。

看完还想把"照到的那一下"保存下来分享,于是有了合成导出;批量产出的图一张张选太累,于是有了文件夹按命名规则批量配对。

## 特性

- **🔦 手电筒光圈** —— 四种光圈模式:手电筒(羽化)、笔刷(更柔)、聚光灯(硬边)、放大镜(带镜头圆环);光圈大小随手调
- **📁 文件夹批量配对** —— 按命名标记自动配对(如 `原-xxx` ↔ `xxx`),一张原图配多张产出,组内翻、组间跳
- **🔍 缩放平移** —— 滚轮缩放、拖拽平移、双击复位,放大了照样精确对比
- **📋 合成导出** —— `Ctrl+C` 复制 / `Ctrl+S` 下载当前合成画面(原图分辨率)
- **📦 单文件导出** —— `Ctrl+E` 把当前一对图导出为交互式单 HTML:光圈、缩放、模式切换、快捷键全都在,发给谁都能打开
- **🛡️ 纯本地、不联网** —— File System Access API 直读本地文件夹,图片绝不上传
- **💾 刷新恢复** —— 上次打开的文件夹记着,刷新后一键授权继续

## 用法

**本地开发**:

```bash
npm install
npm run dev          # 开发服务器
npm run build        # 产出单文件 dist/index.html(可 file:// 双击离线)
npm run build:pwa    # 产出 PWA 多文件 dist/(service worker + manifest,可安装离线)
```

**基本流程**:选一对图(或打开文件夹批量配对)→ 鼠标悬停查看 → `1-4` 切光圈模式、`[ ]` 调大小 → 满意后 `Ctrl+S` 保存或 `Ctrl+E` 导出交互 HTML。

## 快捷键

| 操作 | 作用 |
|---|---|
| `↑/↓` / `空格` / `退格` | 上一组 / 下一组原图 |
| `←/→` | 切换组内产出 |
| `1-4` | 切换光圈模式 |
| `[` `]` `,` `.` | 调光圈大小 |
| 滚轮 / 拖拽 / 双击 | 缩放 / 平移 / 复位 |
| `Ctrl+滚轮`、拖拽中滚轮 | 调光圈大小 |
| `Ctrl+C` / `Ctrl+S` | 合成复制 / 合成下载 |
| `Ctrl+E` | 导出交互式单文件 HTML |

> 导出的 HTML 内置 `?` 帮助浮层,收件人按 `?` 即可查看全部快捷键。

## 浏览器支持

文件夹批量配对、刷新恢复依赖 File System Access API(Chrome / Edge / Opera);直接选两张图的方式不限浏览器。
